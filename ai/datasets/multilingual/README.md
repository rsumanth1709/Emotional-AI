# MindCare AI -- Global Multilingual Human Languages Repository

Cataloged and downloaded emotion, sentiment, and language detection datasets covering **82 human-understandable languages**.

## 🌍 Human Languages Catalog Highlights

| Family | Languages Included | Script Support |
|---|---|---|
| **Indo-European (Germanic & Romance)** | English, German, Dutch, Swedish, Spanish, French, Italian, Portuguese, Romanian, Catalan | Latin |
| **Indo-European (Slavic & Baltic)** | Russian, Ukrainian, Polish, Czech, Slovak, Bulgarian, Serbian, Croatian, Lithuanian | Cyrillic & Latin |
| **Indo-Aryan & Iranian** | Hindi, Bengali, Marathi, Gujarati, Punjabi, Urdu, Nepali, Sinhala, Persian, Pashto | Devanagari, Gurmukhi, Arabic |
| **Dravidian** | Telugu, Tamil, Kannada, Malayalam | Telugu, Tamil, Kannada, Malayalam scripts |
| **Sino-Tibetan, Japonic, Koreanic** | Chinese (Simp & Trad), Japanese, Korean, Burmese | Han, Kanji, Kana, Hangul, Myanmar |
| **Afro-Asiatic & Austronesian** | Arabic, Hebrew, Amharic, Indonesian, Malay, Tagalog, Vietnamese, Thai | Arabic, Hebrew, Ge'ez, Thai, Latin |
| **African Languages** | Swahili, Yoruba, Igbo, Hausa, Zulu, Xhosa, Shona | Latin |
| **Code-Switched Hybrids** | Hinglish, Tenglish, Spanglish, Tanglish, Benglish | Latin (Transliterated) |

## 📄 Repository Datasets
1. **`languages_iso639_manifest.json`**: Complete ISO-639-1 / ISO-639-2 taxonomy for 82 human languages.
2. **`multilingual_sentiment_emotions.csv`**: Benchmark emotion records across Spanish, French, German, Italian, Portuguese, Hindi, Arabic.
3. **`transliterated_code_switched_lexicon.csv`**: Code-switched hybrid emotion corpus (Hinglish, Tenglish, Spanglish, Tanglish).
